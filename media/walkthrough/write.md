# 原稿エディターで書く

サイドバーの **作品一覧** で作品を開き、話を押すと、原稿エディターで開きます。

- ルビと傍点が、振り仮名と圏点で出ます
- 登場人物・場所などの用語が色分けされ、右クリックから設定資料へ飛べます
- 上の列は［入力］［出力］［補助］［表示］の4つです。押すと下にその段が開きます
- 縦書きと横書きは、上の列の［表示］→［縦書きにする］／［横書きにする］で切り替えられます（原稿ごとに覚えます）
- 読み上げは［出力］→［読み上げ］、ルビと傍点は［補助］→［ルビ］［傍点］、口述は［入力］→［口述］です
- 保存は Ctrl+S か、下の欄の右端の［保存］です（下に「保存しました」と出ます）。いちばん新しい話は、下の欄の［最新話］で開けます
- Ctrl+F で本文を探す、Alt+↑／↓ で前後の話、Ctrl+Alt+R でルビ、Ctrl+Alt+K で傍点（傍点の付いた所なら外れる）、Ctrl+＋／－ で字の大きさ
- Ctrl+Alt+T でこの話の誤字脱字、Ctrl+Alt+P で推敲、Ctrl+/ でメモを足す、F8／Shift+F8 で次・前のメモ、Ctrl+Alt+M で校正・メモパネル、Ctrl+Alt+C でAIに相談（キーは「キーボード ショートカット」で「統合小説執筆環境」と探すと変えられます）

続きを書く日は **簡単ステップメニュー › 3. 作品執筆** の「再開用資料」から始めると、前回までの流れを振り返れます。
