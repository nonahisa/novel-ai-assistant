# 原稿エディターで書く

サイドバーの **作品一覧** で作品を開き、話を押すと、原稿エディターで開きます。

- ルビと傍点が、振り仮名と圏点で出ます
- 登場人物・場所などの用語が色分けされ、右クリックから設定資料へ飛べます
- 上のバーで縦書きと横書きを切り替えられます（原稿ごとに覚えます）
- 保存は Ctrl+S です（下に「保存しました」と出ます）
- Ctrl+F で本文を探す、Alt+↑／↓ で前後の話、Ctrl+Shift+R でルビ、Ctrl+Shift+K で傍点、Ctrl+＋／－ で字の大きさ

続きを書く日は **簡単ステップメニュー › 3. 作品執筆** の「執筆再開用資料生成」から始めると、前回までの流れを振り返れます。
