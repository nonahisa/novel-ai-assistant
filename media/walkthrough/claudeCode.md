# Claude Code とつなぐ（任意）

VS Code 版の Claude Code を使っている人向けです。

つなぐと、Claude Code のチャットで「/」から「novel-ai-assistant:setup」を選び、会話しながら最初の作品まで準備できます。

- 押す前に、何をどこへ書くかを見せて確かめます
- 作品を作る・入れるのはこの拡張機能で、どの段もいつもの確認が出ます
- 作品を読ませるかどうかは、別に決めます（**詳細メニュー › 作品管理 › 作品別設定 › 外部AI許可／取消**）

Claude Code を使っていなければ、この段は飛ばして構いません。

あとから開くときは **詳細メニュー › 作品管理 › 作品別設定 › Claude Code接続** です。
