# 作品を用意する

| したいこと | 押すもの |
|---|---|
| これから書く。先に筋を立てたい | プロット起点 |
| これから書く。まず本文から | 本文起点 |
| 投稿サイト（カクヨム・なろう・アルファポリス）のバックアップがある | バックアップ取込 |
| 原稿の入ったフォルダーがある | フォルダー登録 |
| 別のパソコンで書いていて、GitHub に置いてある | GitHubから追加 |

どれを選んでも、原稿のファイルはそのまま残ります。

同じ入口は **簡単ステップメニュー › 1. 作品登録** にも並んでいます。
全部の入口は **詳細メニュー › 作品管理 › 新規執筆開始**・**詳細メニュー › 作品管理 › 既存原稿登録**・**詳細メニュー › 作品管理 › クラウド取得** にあります。
