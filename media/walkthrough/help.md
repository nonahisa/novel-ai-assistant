# 困ったら

| こんなとき | 押すもの |
|---|---|
| 何をどの順で押せばよいか分からない | 場面別案内 |
| やりたいことを言葉で訊きたい | 相談パネルを開く |
| 何ができるのかを一望したい | 使い方 |

**場面別案内**は、新作の始め方・原稿の登録・推敲・矛盾・投稿の準備などから場面を選ぶと、押す場所を順に光らせて案内します。押すのはあなたです（代わりに押すこともできます）。

**相談パネル**では、「矛盾を洗いたい」のように訊くと、答えの下に「画面で案内してもらう」が出ることがあります。

あとから開くときは **詳細メニュー › ヘルプ › 場面別案内**・**詳細メニュー › ヘルプ › 使い方**・**詳細メニュー › 作品執筆 › 相談・助言 › 相談パネルを開く** です。
