GitHub のつなぎ方
  1. claude.ai の設定 → コネクターで、カスタムコネクター「GitHub」（https://api.githubcopilot.com/mcp/）を足す
  2. GitHub の Settings → Applications → Installed GitHub Apps で「Claude Github MCP Connector」の Configure を開く（まだなら、コネクターをつなぐときの案内からインストールする）
  3. Repository access の Only select repositories に、作品のリポジトリを足して保存する（インストールのあとにエラーの画面が出ても、気にしなくて大丈夫です）
  4. このページに戻り、リポジトリの名前を入れて［読む］を押す。最初の1回は、GitHub を使ってよいかを聞かれます
