# 開発用の意味の検索（dev-search）

開発のセッションが、このリポジトリの文書とコードを**言葉の意味で**探す道具。製品（`src/`）には入っていない。`scripts/devSearch/` にある。

## いつ使うか

- **使う**：言い換えや目的からの問い。「〜の決まりはどこで決めたか」「〜を直すならどのファイルか」「〜はどの節に書いたか」。**grep と並べて1回引く**（grep が当たらないとき、または当たりすぎるとき）
- **使わない**：識別子・関数名・画面の文言が分かっているとき。**grep だけ**で足りる（測りでも、言葉がそのまま在る問いは grep のほうが確か）

## 使い方

```powershell
node scripts/devSearch/search.mjs "ポートを握ったまま応答しない古い Ollama を見分ける仕組みはどこで決めたか"
```

上位10件が `道:始まりの行-終わりの行｜見出しの道（コードは export の名前）｜点数` で1行ずつ出る。**本文は出ない**ので、出た道は `Read`（行の範囲を指定）で確かめる。点数は並べ替えのためで、絶対の目安ではない。

## 出る案内と、そのときの動き

| 出た文 | 意味 | することは |
|---|---|---|
| いまは RAG が使えません（ロック：〈持ち主〉） | 手元の Ollama を別の作業が使っている（共通のロック `%TEMP%\novelai-ollama.lock`）。最大60秒待って取れなかった | **grep だけで進める。** 待たない・ロックを消さない |
| Ollama に届きません… | Ollama が起きていない | grep だけで進める |
| 索引がまだありません／作り直しが要ります | 索引が無い、または変わった窓が300を超えた（古い索引のまま答えている） | **`node scripts/devSearch/search.mjs --rebuild` を裏で**走らせる（`run_in_background`）。終わるまで grep と古い答えで進める |

## 仕組み（直すときのために）

- 探す範囲：`docs/**/*.md`（`docs/下書き/`・`docs/superpowers/` は除く）、`CLAUDE.md`、`.claude/skills/**/*.md`、`src/**/*.ts`
- 全文を2,000字の窓（重なり400字）に切り、頭に見出しの道（コードはファイルの道と export の名前）を付けて、`bge-m3`（手元の Ollama）で埋め込む。全件と内積（総当たり）で上位10件
- 索引は `%LOCALAPPDATA%\novelai-dev-rag\<リポジトリ名>\`（リポジトリの外。ワークツリーでも本体と同じ名前）。ベクトルは Float32 の詰めた形、窓の目録は JSON。鍵は「モデル名＋埋め込む文の SHA-256」で、同じなら埋め直さない
- 問うたびに、変わった窓だけ埋め直す（300を超えたら古い索引のまま答える）
- **ほかのモデルを Ollama から外さない**（製品のセッションや市場分析の邪魔になる）。ロックは終わり・失敗・Ctrl+C で必ず返す
- 試し：`test/unit/cross/devSearch.test.ts`（窓の切り方・埋め直しの判定・上位の並べ方・ロック）
