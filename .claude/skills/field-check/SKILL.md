# 実機確認の進め方

## 守ること

- **開発ホスト（F5）で操作するときは、名前の末尾が `_確認用` の作品だけを使う**（`Documents\確認用コピー\` 配下）。作者の原稿では試さない
- **作者への操作依頼は `AskUserQuestion`（選択肢）で出す。** 「Esc を押してください」を文章で書かない
- **ファイル優先。** 画面を撮るのは「組まれた見た目」と「押して初めて起きること」だけ。ファイル・記録・印で確かめられるものは、こちらで確かめる
- **機械にできる確認はテストへ移す。** 覆った項目は `- [x]（機械で確認：test名）` に、作者が押したものは `- [x]（日付 作者が確認）` に。**済んだ記録は引継ぎ書2章へ写してから、一覧から消す**（不具合・判断待ちは残す）
- **平日は作者の手が要らないテストを優先。** 手が要る項目は溜めて、休みの日にまとめて頼む
- **壊れていると言う前に**：探し方を変えて2通り／押せたことを確かめる／痕跡の作り主を訊く（「やってるはず」と言われたら、印・記録に痕跡があるか見る——2026-09-16、`tools: ["*"]` と時刻で裏付けが取れた）
- **AIの出力が悪いとき、プロンプトのせいだと結論する前にモデルを差し替える**

## 作者と一緒に確かめる形（F-105 で通した型）

**こちらが起こし、作者は画面を見るだけ**にする。作者の手は F5 と「出た／出ない」の返事だけで済む。

1. 手順と「何が出るはずか」を先に書く
2. `AskUserQuestion` で「準備できた」の合図をもらう
3. こちらから撃つ（下の「MCP を別プロセスから撃つ」）
4. 記録・印をこちらで読んで裏付ける（作者の返事と機械の痕跡の両方）
5. 済んだ項目をその場でリストに反映し、コミットする

## MCP を別プロセスから撃つ

**このセッションに繋がっている MCP サーバーは、セッション開始時の古い束のまま**である（`mcp.version` で分かる）。新しい束を使うには別プロセスを起動する。

```powershell
$env:ELECTRON_RUN_AS_NODE = $null
$text = Get-Content -Raw -Encoding utf8 <指示ファイル>
$text | claude -p --mcp-config .mcp.json --allowedTools "mcp__novel-ai-assistant__<道具>,ToolSearch" --model claude-haiku-4-5-20251001
```

- **指示ファイルは UTF-8 で Write する**（日本語パスを引数に直接書かない）。指示は英語で短く、「結果だけ報告・userPrompt は出さない・ほかの道具は呼ばない・再試行しない」を書く
- 道具名は `.` を `_` にした形（`opening.prompt` → `mcp__novel-ai-assistant__opening_prompt`）
- `ToolSearch` を allowedTools に入れないと、Haiku が道具を呼べないことがある
- **束を作り直してから撃つ**（`npm run check` か `npm run build`。`dist/mcp-server.mjs`）

**印と記録の場所**：

| 何 | どこ | 誰が書く |
|---|---|---|
| 許可の印 | `.aiwriter/external-access.json` | **拡張機能だけ**。こちらで書き換えない（設計違反で、分類器も止める）。試すなら**一時フォルダーに作り物の作品**を作って印を置く |
| ノックと利用の記録 | `.aiwriter/history/external.jsonl` | MCP が追記。`ok:false`＋「許可が無いので断りました」がノック |
| 検算の結果 | 道具の返り値 | — |

## AIの出来を実データで測る

- **見逃しと誤検出の両方を数える。** 片方だけでは、何も指摘しない実装が満点になる
- **製品と同じ経路を通す**（`runner: "ollama"`、`*.run`）。`prompt` だけ呼んで `validate` を通さない測り方は、製品に無い不具合を見つけたことになる
- 仕込み（わざと入れた矛盾・誤字）は**一時フォルダーの写し**に入れる。確認用コピーも作者の作品の写しなので、書き換えない
- 測った結果は引継ぎ書8章に「何を・どのモデルで・何件中何件」で残す。実機確認リストの該当項目には `→ **MCP で測れる**：道具名` の道しるべが付いている（2026-09-16、14件）
