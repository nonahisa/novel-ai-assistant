# 作者の手が要るもの（実機確認の残り）

**この一覧は、ノートPC側のセッションが `docs/実機確認リスト.md` から抜き出したものです**（2026-09-21）。

**なぜ分けたか**：この機械では VS Code が「クリックのみ」の階級で動いていて、**打ち込み・右クリック・修飾クリック・ドラッグ・キー操作（Esc／Ctrl+Z／F5／IMEの変換）・OS の窓・人にしか分からない判断**ができません。ここに並ぶのは、その6つのどれかが要るものだけです。**逆に言えば、これ以外は機械の側で潰せます。**

**使い方**：休みの日に、上から順に押していけるように並べてあります。**同じ画面のものを固めて**あるので、1つの画面で往復しないで済みます。**★は特に効くもの**——時間が限られているときは★だけでも。

**結果の書き方**：合格なら行の頭に `✓`、駄目なら `✗` と、**見えたことをそのまま**（文言は写しで、要約しないでください）。分からなかったら `?`。
