# 0.0.1 Initial Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a verified, installable `0.0.1` VSIX containing the existing Phase 0, AI setup, and character-extraction features.

**Architecture:** Preserve the current layered extension architecture. Add runtime validation at the AI boundary, make persistence write only changed records, harden work-folder configuration, and establish separate fast unit and VS Code-hosted integration test gates before packaging.

**Tech Stack:** TypeScript 5.6, VS Code Extension API, esbuild 0.28, Vitest 4, `@vscode/test-electron`, `@vscode/vsce`.

## Global Constraints

- Release version is exactly `0.0.1` in both `package.json` and `package-lock.json`.
- Do not add unfinished roadmap features to this release.
- Never overwrite manuscript content, malformed configuration, or author-owned character fields.
- UI text and explanatory code comments remain Japanese.
- The distributable must not contain source files, design documents, local manuscript paths, credentials, caches, or test artifacts.
