# v0.0.2 Quality Improvement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make v0.0.2 materially safer and more accurate, then publish one verified VSIX through a non-draft GitHub pull request and release.

**Architecture:** Keep VS Code UI orchestration in `src/features/`, move reusable validation and atomic persistence into focused `src/core/` modules, and keep AI output untrusted until deterministic code validates it. Test all safety boundaries locally and in regular GitHub Actions; keep live Sakura/Ollama calls manual.

**Tech Stack:** TypeScript 5.6, VS Code Extension API 1.90.0, Vitest 4, esbuild, `@vscode/test-electron`, `@vscode/vsce`, `iconv-lite`, GitHub Actions, GitHub CLI.

## Global Constraints

- Use two-space indentation, double quotes, strict TypeScript, and no production `any`.
- Write source comments and user-facing messages in Japanese.
- Preserve manuscript bytes: encoding, EOL, trailing newline, hash checks, and conflict-marker blocking are mandatory.
- Never overwrite malformed author JSON, `authorNotes`, `exportNote`, locked address terms, or AI-protected fields of `autoGenerated: false` characters.
- Increment `CHARACTER_EXTRACT_VERSION` whenever the extraction prompt changes.
- Never read, create, modify, or commit `.env`; Sakura uses only `SAKURA_AI_ACCOUNT_TOKEN` in the manual workflow.
- Regular CI must not make live AI calls or receive AI credentials.
- Minimum editor remains VS Code 1.90.0; CI uses Node.js 22.
- Release identity must be exactly `v0.0.2`, package version `0.0.2`, and `novel-ai-assistant-0.0.2.vsix`.

- [ ] **Step 4: Implement same-directory atomic replacement and guarded encoding**

Use this public shape:

```ts
export async function atomicWriteFile(
  filePath: string,
  bytes: Uint8Array
): Promise<void> {
  const destination = vscode.Uri.file(filePath);
  const temporary = vscode.Uri.file(
    `${filePath}.novelai-${process.pid}-${crypto.randomUUID()}.tmp`
  );
  try {
    await vscode.workspace.fs.writeFile(temporary, bytes);
    await vscode.workspace.fs.rename(temporary, destination, { overwrite: true });
  } catch (error) {
    try {
      await vscode.workspace.fs.delete(temporary);
    } catch {
      // 一時ファイルが無い場合は元の失敗を優先する
    }
    throw error;
  }
}
```

Encode Shift_JIS with `iconv.encode(text, "shift_jis")`, decode it again, and return `encoding_error` unless the decoded text equals the requested text. Before atomic writing, reject dirty open documents, current/output conflict markers, missing files, and hash mismatches.
