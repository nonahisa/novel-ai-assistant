作者の依頼（2026-10-22）で作った、実装の進み具合の欄。Claude アプリの横のパネル（使用量と進み具合）が、この欄の `- [ ]`／`- [x]` を数えて「実装 ◯%（済み／全体）」を出す。

- 頼まれた実装・決まった直しを1行ずつ置き、入ったら `- [x]` にして版を添える
- 不具合の疑いで、直すかどうかが決まっていないものは置かない（決まったら置く）
- 実機での確かめは `実機確認リスト.md` の側で数える
