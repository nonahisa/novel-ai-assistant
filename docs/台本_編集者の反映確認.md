# 編集者の反映確認（kmizu さん向け）

2026-11-07 作成。作者（hisa）が採否を送り返したあと、kmizu さんの環境（編集者モード）にそれがきちんと届いたかを確かめる手順です。画面の名前と知らせの文は 0.134.6 の製品から引いています。作者と一緒に通す台本（通しの台本）の kmizu さんの段と、番号を添えて対応させています。

- **作品**：「たゆたう鉛 - 実験用」
- **⏸ の印**：作者からの連絡を待つ所
- **📷 の印**：画面の写真を撮って、作者へ送る所
- **各段の結果**：「済み」か「つまずいた＋一言」を書く。つまずいたら、その画面の写真も作者へ送る
- **N の数**：作者が決めた数です。作者からの連絡に「採用 N・見送り N・読まれた N」が書いてあるので、その数と比べてください

**よく出てくる場所**
- **横の枠**：VS Code の左端に縦に並んだアイコンから「統合小説執筆環境」のアイコンを押すと、横に開く枠
- **編集者メニュー**：横の枠のいちばん上の見出し。編集者モードのときだけ出る。作品の行と、その下の「校閲中の話」「置いた提案」「作者の採否」「受け取り」の4行（上の件数）、手順「1.」〜「7.」、いちばん下の「ヘルプ」「作者モードへ戻る」が並ぶ
- **手順の印**：手順「1.」〜「7.」の右に「✓ 済み」「▶ 次はここ」「・ まだ」のどれかが出る
- **下の帯**：VS Code の窓のいちばん下の細い帯。同期していないものがあると「未取得 1 / 未記録 1」のように出る
- **開き直す**：VS Code の窓を閉じて、もう一度開く（または Ctrl+Shift+P〈Mac は ⇧⌘P〉→「Developer: Reload Window」）

## 段0. 拡張機能を 0.134.6 以降へ上げる（通しの台本の段0-2）

**作者が採否を送り返す前に済ませてください。** 上げるときに VS Code を開き直すので、採否が届いたあとに上げると、段2で見る知らせが先に出てしまいます。

### 0-1. 拡張機能を上げる
- **どこで**：VS Code の左端に縦に並んだアイコンから「拡張機能」（四角が4つのアイコン）を押す → 上の検索欄に「統合小説執筆環境」と打つ → 出てきた「統合小説執筆環境」（発行者 nonahisa）を押す
- **押す**：［更新］が出ていれば押す。続けて［再起動］か［拡張機能を再起動］が出たら、それも押す（［更新］が出ていなければ、もう上がっている）
- **合格**：［更新］のボタンが消える

### 0-2. 版を確かめる
- **どこで**：横の枠 → 編集者メニューのいちばん下の「ヘルプ」を押して開く →「バージョン確認」
- **合格**：真ん中に出た窓の1行目が「統合小説執筆環境 0.134.6」（それより大きい数でもよい）

📷 版の窓を撮って、作者へ送る

⏸ 作者からの連絡を待つ（「採否を送り返しました」の連絡）

## 段1. 開く前の様子を見る

作者から連絡が来たとき、VS Code を開いたままなら、閉じずにそのまま見てください。閉じていたなら、この段は飛ばして段2へ進んでください（開いたときに自動で受け取るので、受け取る前の様子は見られません）。

- **どこで**：下の帯と、横の枠の編集者メニュー
- **合格**：下の帯に「未取得 1」が入っている（「未取得 1 / 未記録 1」のように出る）。編集者メニューの「受け取り」の行に「作者の新しい原稿があります（未取得 1）」、手順「1. 作者の最新の原稿を受け取る」の右に「▶ 次はここ」
- 開いたまま待っていると、このときもう「作者が提案を決めました…」が出ることがあります。出たら段2の 2-1 の合格として書き、2-1 は開き直しだけを行う

📷 下の帯と編集者メニューを撮って、作者へ送る

## 段2. 開き直すと受け取り、知らせが1回だけ出る（通しの台本の段8-1）

### 2-1. 開き直す
- **押す**：VS Code を開き直す
- **合格**：右下（または下の帯）に「作者が提案を決めました（採用 N・見送り N・読まれた N）。」が1回出る。N は作者からの連絡の数と同じ。下の帯の「未取得」「未記録」が消える（帯の同期の表示そのものが消える）

📷 知らせと下の帯を撮って、作者へ送る

### 2-2. もう一度開き直す
- **押す**：VS Code をもう一度開き直す
- **合格**：「作者が提案を決めました…」は、もう出ない。下の帯にも「未取得」「未記録」は出ない

---

## 段3. 編集者メニューの印と件数が、返った採否に合っている

- **どこで**：横の枠の編集者メニュー
- **合格（上の件数）**：
  - 「校閲中の話：なし（前の回は作者へ返しました）」
  - 「置いた提案：M件（作者へ返しました）」（M は前に返した提案の数）
  - 「作者の採否：採用 N・見送り N・読まれた N」（作者からの連絡と同じ数。「返事待ち」や「新しく届いた」は付かない）
  - 「受け取り：最後に受け取ったのは 今日 …・最新です」
- **合格（手順の印）**：手順「1.」〜「6.」が「✓ 済み」。「7. 作者の採否を見る」は「✓ 済み」か、右に「新しい採否 N件」が付いた「▶ 次はここ」（段4で一覧を開くと「✓ 済み」になる）

📷 編集者メニュー全体を撮って、作者へ送る

---

## 段4. 採否の中身を見る（通しの台本の段8-2）

- **どこで**：編集者メニュー →「7. 作者の採否を見る」
- **合格**：上に一覧が出る。題は「たゆたう鉛 - 実験用：作者の採否（採用 N・見送り N・読まれた N）」。行は「採用　「元の語」→「直した語」」「見送り　「元の語」→「直した語」」「読まれた　「選んだ所」への意見」の形で、右に「episode_000N.txt N行」
- **合格（意見だけの提案）**：意見だけ（直す案を空にした）の提案は「読まれた」と出て、「採用」には入っていない。題の「読まれた」の数に入っている
- 一覧を閉じたあと、編集者メニューの「7. 作者の採否を見る」の印が「✓ 済み」になる

📷 一覧を撮って、作者へ送る

---

## 段5. 作者が採った直しが、手元の本文に入っている

- **どこで**：段4の一覧で「採用」の行を1つ選ぶ（本文のその場所が開く）
- **合格**：開いた本文の、その行に「直した語」が入っている（元の語のままではない）
- **あわせて**：「見送り」の行を1つ選び、本文が元の語のままであることを見る

📷 採用の行が開いた本文を撮って、作者へ送る

⏸ 作者からの連絡を待つ（「原稿を1か所直して送りました」の連絡）

---

## 段6. 「保存・同期」は受け取るだけ（通しの台本の段2-2・段5-1）

- **どこで**：編集者メニュー →「1. 作者の最新の原稿を受け取る」
- **合格（押す前）**：真ん中に窓が出る。1行目は「1か所で、作者の最新の原稿を受け取ります。」。下の説明に「受け取るだけで、GitHubへは何も送りません。提案は「校閲を終えて返す」で作者へ届きます。」。ボタンは［受け取る］
- **押す**：［受け取る］
- **合格（押したあと）**：作者が直した所が手元の本文に入る。こちらから GitHub へは何も送られない（作者の側で、GitHub に kmizu さんの新しい記録が無いことを確かめる）。受け取るものが無いときは、窓は出ない

📷 窓を撮って、作者へ送る

---

## 段7. 作者モードへ戻す（通しの台本の段10。試しが全部済んでから）

- **どこで**：編集者メニューのいちばん下の「作者モードへ戻る」
- **合格**：横の枠から編集者メニューが消え、「簡単ステップメニュー」が出る
- 続けて作者と編集の試しをするときは、戻さずにそのままにしておく

## うまくいかないとき

- 押しても何も起きない・理由の知らせが出る：その知らせの文をそのまま作者へ送る
- 段2で「作者が提案を決めました…」が出ない：開き直す前に、すでに出ていなかったか（段1）を思い出して作者へ伝える。出ていなければ、下の帯と編集者メニューを撮って作者へ送る
- 数が作者の連絡と合わない：編集者メニューと「7. 作者の採否を見る」の一覧を撮って作者へ送る
- 迷ったら、その場の画面の写真を作者へ送る
