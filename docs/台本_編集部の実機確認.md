# 台本：編集部の実機確認・通し（hisa × kmizu さん）

2026-11-07 作り直し（0.134.6 に合わせて、最初から最後までを1本にした）。画面の名前・メニューの場所・知らせの文は 0.134.6 のソースから引いた。結果を書き込むページ（作者だけが見られるアーティファクト）も同じ中身である。

- **使う作品**：「たゆたう鉛 - 実験用」（作品一覧に出ている名前で選ぶ）
- **二人**：hisa（作者）・kmizu さん（編集者）。母艦（Claude）は段ごとに GitHub と作品の中の記録を読んで、結果を確かめる
- **⏸ の印**：そこで相手の段が済むのを待つ。済んだら、チャットなどで相手に一言伝える
- **各段の結果**：「済み」か「つまずいた＋一言」を書く。つまずいたら、その画面の写しを母艦へ送る
- **範囲の例**：校閲する範囲は「第2話〜第3話」、範囲の外は「第5話」とする。違う範囲にするときは、読み替える

**よく出てくる場所**
- **詳細メニュー（hisa）**：VS Code の左端の縦に並んだアイコンから「統合小説執筆環境」のアイコンを押す → 横に開いた枠の中の「詳細メニュー」の見出しを押して開く
- **編集者メニュー（kmizu さん）**：VS Code の左端の「統合小説執筆環境」のアイコンを押す → 横に開いた枠のいちばん上の「編集者メニュー」。編集者モードのときだけ出る
- **提案パネル**：知らせの［提案を見る］から開く。下の段に「提案」のタブとして出ることもある

- **確かめる**：編集者モードなら、編集者メニューのいちばん下の「ヘルプ」→「バージョン確認」。作者モードなら、詳細メニュー →「ヘルプ」→「バージョン確認」

## 段1. hisa：編集者へ渡す（送り直す）

- **どこで**：VS Code の左端の「統合小説執筆環境」のアイコン → 横の枠の「作品一覧」で「たゆたう鉛 - 実験用」を押して選ぶ → 同じ枠の詳細メニュー →「作品管理」→「編集者連携」→「編集者へ渡す」

- **合格**：右下に「「たゆたう鉛 - 実験用」を編集者へ送り直しました。」（初めてのときは「…を編集者へ渡し、kmizuさんを招待しました。招待のリンク：…」と［リンクを写す］）
- 招待のリンクが出たときだけ、［リンクを写す］を押して kmizu さんへ送る

⏸ kmizu さんへ「渡しました」と伝える

## 段2. kmizu さん：参加して、作者の最新の原稿を受け取る

### 2-1. 参加する（前に参加している場合は、ここで分かる）
- **どこで**：作者モードなら、VS Code の左端の「統合小説執筆環境」のアイコン → 詳細メニュー →「作品管理」→「編集者連携」→「編集者として参加」。編集者モードなら、編集者メニューの「参加のリンクを貼る」（作品があるときは「作品を足す（参加のリンクを貼る）」）
- **押す**：hisa から届いたリンクを貼って Enter → 真ん中の窓の［参加する］
- **合格（初めて）**：「「たゆたう鉛 - 実験用」に編集者として参加しました。開いたときに、作者からの更新が自動で取り込まれます。」。横の枠のいちばん上に「編集者メニュー」が出る
- **合格（前に参加している）**：「「たゆたう鉛 - 実験用」には、もう編集者として参加しています。作者の最新の原稿を受け取るには、編集者メニューの「1. 作者の最新の原稿を受け取る」を押してください。」。このときは 2-2 へ進む

### 2-2. 作者の最新の原稿を受け取る
- **どこで**：編集者メニュー →「1. 作者の最新の原稿を受け取る」
- **押す**：真ん中の窓に「N か所で、作者の最新の原稿を受け取ります。」が出たら［受け取る］（受け取るものが無ければ窓は出ない）
- **合格**：窓に「受け取るだけで、GitHubへは何も送りません。」と書いてある。押したあと、GitHub へは何も送られない（母艦が GitHub の記録で確かめる）

## 段3. kmizu さん：校閲する話を選ぶ（範囲の新しい知らせ）

- **押す**：上に出る一覧で、「校閲する範囲：始めの話を選びます」で第2話 →「校閲する範囲：終わりの話を選びます」で第3話 →「何をしているかを、作者へ伝えます」で「校閲中」

- 「校閲中の範囲を、作者へ知らせられませんでした…」と出たら、つまずいたとして書く（範囲は返すときに届くので、続けてよい）

⏸ hisa へ「範囲を選びました」と伝える

## 段4. hisa：校閲中の範囲は書けず、範囲の外は書ける

### 4-1. 範囲の知らせを受け取る
- **どこで**：詳細メニュー →「作品管理」→「GitHub作品管理」→「保存・同期」（または VS Code を閉じて開き直す）
- **合格**：「編集者が第2話〜第3話を校閲中です。」の知らせ

### 4-2. 範囲の話は原稿エディターで書けない
- **どこで**：作品一覧で「たゆたう鉛 - 実験用」の第2話を押して原稿エディターで開く
- **押す**：本文のどこかに1字打つ
- **合格**：「「episode_0002.txt」は編集者が校閲中のため、書けません（…）。」の知らせと［連携を解除…］。打った字は本文に入らない

### 4-3. 範囲の外の話は書けて、編集者へ送られる
- **どこで**：作品一覧で第5話を開く
- **押す**：1行書き足して保存 → 詳細メニュー →「作品管理」→「GitHub作品管理」→「保存・同期」
- **合格**：普通に書けて、同期も通る

⏸ kmizu さんへ「確かめました。原稿を1か所直しました」と伝える

## 段5. kmizu さん：受け取るだけの「保存・同期」と、提案を置く

### 5-1. 作者の直しを受け取る（受け取るだけ）
- **どこで**：編集者メニュー →「1. 作者の最新の原稿を受け取る」
- **押す**：窓の［受け取る］
- **合格**：窓に「1 か所で、作者の最新の原稿を受け取ります。」のように出て、押すと hisa が足した第5話の行が入る。GitHub へは何も送らない

### 5-2. 機械に探させて［適用］する（提案として置かれる）
- **どこで**：編集者メニュー →「3. 機械に探させる」→「表記ゆれ検知」
- **押す**：提案パネルに並んだ指摘のうち、2件以上に［適用］
- **合格**：本文は変わらない（提案として置かれる）

### 5-3. 修正を提案する（直す案つき）
- **どこで**：第2話か第3話を開き、直したい語を選ぶ → 右クリック →「修正を提案する」（または編集者メニュー →「4. 直しを提案する・メモ（意見）を書く」→「修正を提案する」）
- **押す**：「修正を提案する（1/2）：修正案」に直す案を入れて Enter →「修正を提案する（2/2）：理由・意見」に理由を入れて Enter
- **合格**：本文は変わらず、下の帯に「episode_000N.txt N行目に提案を置きました。「校閲を終えて返す」で作者へ届きます。」
- 選ばずに押すと「修正したい所を本文で選んでから押してください（右クリックからも出せます）。」と出る（これも合格）

### 5-4. 意見だけを置く（直す案なし）
- **どこで・押す**：別の所を選んで、5-3 と同じ「修正を提案する」→ 修正案を**空のまま** Enter → 意見を書いて Enter
- **合格**：5-3 と同じく「…行目に提案を置きました。…」。本文は変わらない

## 段7. hisa：届いた提案の採否を決める

### 7-1. 提案が届く
- **どこで**：詳細メニュー →「作品管理」→「GitHub作品管理」→「保存・同期」（または VS Code を開き直す）
- **合格**：「編集者から提案が N 件届きました」と［提案を見る］、「第2話〜第3話の校閲が終わりました。」
- 知らせを見逃したら：詳細メニュー →「作品管理」→「編集者連携」→「編集者の提案を見る」

### 7-2. 意見に［読んだ］、直しの1件に［見送る］
- **どこで**：［提案を見る］で開いた提案パネル
- **押す**：5-4 の意見の行の［読んだ］（意見だけの行は［適用］でなく［読んだ］が出る）。直しの提案のうち1件の［見送る］
- **合格**：意見を読んでも本文は変わらない。見送った所も本文はそのまま

### 7-3. 残りをまとめて適用する
- **どこで**：同じ提案パネル
- **押す**：［まとめて適用］→ 窓の［適用する］
- **合格**：採った提案のとおりに本文が変わる。決め終えると、下の帯に「採否を編集者へ送り返しました（採用 N・見送り 1・読まれた 1）。」（送り返しの確認の窓は出ない。手で渡し直す必要は無い）
- まとめて適用で残ったもの（確信度が低いものなど）は、1件ずつ［適用］か［見送る］で決め終える

### 7-4. 範囲だった話がまた書ける
- **どこで・押す**：第2話を原稿エディターで開き、1字打って元に戻す
- **合格**：普通に書ける

⏸ kmizu さんへ「決めました」と伝える
