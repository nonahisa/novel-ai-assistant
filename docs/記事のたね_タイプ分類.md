# 記事のたね——作者タイプと読者タイプ

note の記事を書くときの材料。**製品が実際に持っている分類**をそのまま写してある（設計書 6.86 と 6.91）。

**記事と製品が食い違うと、読んだ人が試したときに裏切られる。** 数字や呼び名を変えたくなったら、先に製品のほうを直すこと。

---

## 芯になる考え

**作者にも読者にも、上下は無い。** どちらの分類も「あなたはここが足りない」ではなく「あなたにはこういうものが効く」と言うために作ってある。

そして**両方とも3軸・11分類**で、呼び名を揃えてある。

| | 軸 | 分類 | 呼び名 |
|---|---|---|---|
| 作者 | 読者志向・自分志向・嗜好志向 | 11 | 「〜**型**」 |
| 読者 | 読み慣れ・読む姿勢・求めるもの | 11 | 「〜**層**」 |

**「型」と「層」で分けてあるのは、画面で並んだときに取り違えないため。** 記事でも守ると、読者が混乱しない。

### なぜ3軸なのか

**2軸だと足りず、4軸だと自分がどこにいるか分からなくなる。** 3軸なら、立方体の隅として思い浮かべられる。

### 年齢層を軸にしない

読者の分類で、いちばん聞かれそうなところ。製品はこう書いている。

> 年齢層は軸にしていません。同じ年頃でも、隙間に読む人と腰を据えて読む人では、効く書き方がまるで違うためです。

**年齢は結果であって、書き方を決めるものではない。** 記事でもこの一文はそのまま使える。

## 作者タイプ（設計書 6.86）

### 3つの軸

| 軸 | 低 | 中 | 高 |
|---|---|---|---|
| **X 読者志向** | 読者は視界にない | 意識はするが優先はしない | 読者基準で判断する |
| **Y 自分志向** | 自分を出す意識が薄い | 自分の色は保ちたい | 作品＝自分 |
| **Z 嗜好志向** | 題材は目的の手段 | 好きな題材はあるが可変 | 題材そのものが目的 |

各軸3問・各問0〜2点で、合計0〜6。**0〜1が低、2〜4が中、5〜6が高。**

### 11のタイプ

**主軸**＝いちばん高い軸。**副軸**＝残りのうち中以上でいちばん高いもの。

| 主軸 | 副軸 | 名称 | どういう助言が効くか |
|---|---|---|---|
| 読者志向 | なし | **読者最適型** | 具体的な技術論。根拠があればテーマも |
| 読者志向 | 自分志向 | **発信表現型** | 伝えたい内容を確かめてから技術論 |
| 読者志向 | 嗜好志向 | **題材職人型** | 「この題材が届く層」の市場分析 |
| 自分志向 | なし | **内省表現型** | 抽象・比喩寄り。強い言葉は避ける |
| 自分志向 | 読者志向 | **対話表現型** | 意図の翻訳を手伝う形 |
| 自分志向 | 嗜好志向 | **世界没入型** | 世界観の内的整合から入る |
| 嗜好志向 | なし | **嗜好探究型** | 題材への共感が先、技術論は後 |
| 嗜好志向 | 読者志向 | **共感共有型** | 同好者への届け方 |
| 嗜好志向 | 自分志向 | **私的神話型** | 題材の解釈を確かめてから触れる |
| 全部が中 | — | **均衡模索型** | 方向づけの相談。**最も助言が効く帯** |
| 全部が低 | — | **目的模索型** | 「何のために書くか」の掘り起こしから |

### 記事で触れないほうがよいこと

製品は内部で**受容度**（指摘をどれくらい受け取れるか）と**自信度**（作品への手応え）も推定しているが、**作者には聞かないし見せない。**

> 本人に見せると「自信のない人」というラベルになり、それ自体が地雷になる。

**記事でも出さないほうがよい。** 「AIが自分の自信を測っている」と読まれると、道具への信頼が壊れる。

## 読者タイプ（設計書 6.91）

**作者ごとではなく、作品ごとに決まる。** 同じ作者が異世界転生と純文学を書いていれば、ターゲット読者は別物だからである。ここが作者タイプとの対比になる。

### 3つの軸

| 軸 | 低い側 | 高い側 |
|---|---|---|
| **読み慣れ** | その題材が初めて | 読み尽くしている |
| **読む姿勢** | 隙間に読む | 腰を据えて読む |
| **求めるもの** | 気持ちよさ | 揺さぶり |

**どちらが上等でもない。** 「高いほうが良い」と読めると、作者が自分の読者像を格付けされたように感じる。

### 11の層

| 名称 | 何を求めて読むか | 効くこと | 離れるところ |
|---|---|---|---|
| **回遊層** | 読み尽くしていて、次々と渡り歩く | 本題まで早く着く | 知っていることを長く説明される |
| **考察層** | 伏線を拾い、読み返し、辻褄を見る | 回収される伏線と設定どうしの筋 | 後から設定が変わる |
| **開拓層** | まだ見ていないものを探している | 型を承知のうえで外す | どこかで読んだ展開 |
| **没入層** | 作品の世界に浸かりに来る | 世界の手触り・情景・空気 | 急ぎ足の展開 |
| **常連層** | 気に入った書き手を追いかける | 更新が続くこと・積み重ね | 間が空くこと |
| **感涙層** | 心を動かされに来る | 溜めてから放つこと | 溜めの無い悲劇 |
| **刺激層** | 動きの止まらない話を探す | 毎話なにかが起きる・引きが強い | 静かな話が続く |
| **裏読み層** | お約束が崩れる瞬間を待つ | 型を踏ませてから裏切る | 予想どおりに進む |
| **余韻層** | 読んだあとも考えていたい | 言い切らずに終える | 全部を説明して閉じる |
| **雑食層** | 面白ければ何でも読む | 作品ごとの持ち味 | 何が売りか分からない |
| **すきま層** | 空いた時間に気持ちよく読める話 | 短く・分かりやすく・次が気になる | 長い導入 |

**すきま層は「WEB小説でいちばん数の多い層」**と製品が明記している。記事の落としどころとして使いやすい。

## 記事にするときの勘どころ

### 1. 「診断」と言い切らない

**品定めではない。** どちらの分類も「あなたにはこういうものが効く」を出すための道具である。製品の書き方に合わせると、読んだ人が身構えない。

### 2. 作者タイプと読者タイプは別物

- **作者タイプは作者ごと**（その人がなぜ書くか）
- **読者タイプは作品ごと**（その作品が誰に届くか）

同じ人が両方を持ち、**しかも作品を変えれば読者タイプは変わる。** ここを混ぜると記事が破綻する。

### 3. 11分類のうち2つは「隅ではない」

**均衡模索型／目的模索型**（作者）と**雑食層／すきま層**（読者）は、立方体の隅ではなく**真ん中や手前**にいる。図でもそう描いてある。

「どこにも尖っていない」ことを弱点として書かないこと。製品は均衡模索型を**「最も助言が効く帯」**と書いている。

### 4. 数字は出してよいが、点数表は出さない

「各軸3問・0〜6点」までは書いてよい。**質問そのものを記事に写すと、読んだ人が答えを作ってから診断を受ける。**
