## 利用者
- 小説家になろうのユーザー ID：（作者さんが入れる）
- 立場：小説家になろうに作品を投稿している個人の作者。開発しているツールは、自分の執筆のために作り、無料で公開しているもの

## 利用したい API
- なろう小説API（自分の作品の評価ポイント・ブックマーク数・評価者数・話数・更新日など）
- 現時点ではまだ使っていません。ガイドラインに沿うかを確かめてから使うかどうかを決めたく、回答しています

## 利用目的
- 自分が投稿している作品について、読者の反応（ポイントやブックマークの推移）を自分の手元で振り返り、執筆に生かすため
- 統合小説執筆環境という、小説を書くための無料の道具（VS Code の拡張機能）に、作者が自分の作品の数を手元で見る機能として組み込むことを考えています

## 使い方（取得の範囲と頻度）
- 取得するのは、利用者がその道具に登録した、利用者本人の作品だけです。他人の作品を集めたり、ランキングを作ったりはしません
- 利用者がボタンを押したときだけ取得します。自動で繰り返し取得することはしません（1作品につき1回の呼び出しを、多くても1日に数回）
- 取得したデータは、利用者のパソコンの中の作品フォルダーにだけ保存し、第三者に渡したり、公開したり、再配布したりはしません

## 商用か
- 道具は無料で、広告もアフィリエイトもありません。有料の機能もありません

## AI との関係
- 取得したデータを AI の学習には使いません
- 道具には AI に相談する機能がありますが、なろう小説API から取得したデータは AI に渡さない作りにします

## 出典の表示
- 取得した数を表示する画面に、出典として「なろうデベロッパー（なろう小説API）」と書きます

## 管理
- 道具は作者本人が継続して保守しています（Visual Studio Marketplace で公開中、更新を続けています）

## 確かめたいこと
- 作者が自分の作品の反応を見るために、無料の執筆ツールの中からなろう小説API を使うことは、ガイドラインの「利用可能な目的」に当たるでしょうか
- 当たらない場合、どのような形であれば利用できるでしょうか
