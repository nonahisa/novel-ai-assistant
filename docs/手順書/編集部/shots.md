# 編集部向け手順書の画面ショット（説明の下書き）

撮った台本：`test/e2e/manual/editorManual.shots.ts`（撮り直しは `npm run manual:shots`）。
拡張機能 0.127.5（main）、VS Code 1.141.0、窓 1280×800。作品は台本の中の作り話「春を待つ灯（見本）」（3話）で、編集者モードで撮った（2026-11-05 に34枚すべてを撮り直した）。
赤い楕円が「次に押す所」（11 だけは「見てほしい知らせ」）。どの画像も、押す所の周りを切り出した `_拡大` 付きの2枚目がある。
下の説明の名前は今の拡張機能に合わせてある。画像のファイル名には撮った時の古い名前（「編集部」「直した案」など）が残っている。
手順書の HTML と PDF は `作り方/`（`型紙.html` の `{{IMG:名前}}` を `build.mjs` が埋め込む。PDF は Edge のヘッドレスの `--print-to-pdf`）で作る。HTML・PDF は git に入れない。

撮るときの前提（手順書の本文で触れるか、リーダーが判断）：

- 試験用の VS Code には日本語の言語パックが入っていないので、VS Code 本体の部分（メニューバーの File／Edit、確認の窓の［Cancel］、入力欄の下の「Press 'Enter' to confirm…」）は英語で写っている。拡張機能の文言はすべて日本語
- 左の列の「作品一覧」は畳んで撮った（編集部は作品1つだけなので、簡単ステップメニューの「選択作品」の行に題が出る）
- 下の帯の右の「未記録 1／4」は、提案やロックの記録がまだ送られていない印。編集部の操作では気にしなくてよい（返すときに送られる）

## 01 アイコンと簡単ステップメニュー

- `img/01_アイコンと簡単ステップメニュー.png`
- 左の端の「統合小説執筆環境」のアイコン（ペンの絵）を押すと、左の列に「簡単ステップメニュー」が出る。編集者モードでは「1. 編集者として参加」〜「7. 作者モードへ戻る」の7段と「ヘルプ」が並ぶ。上から順に進める。

## 02 詳細メニューの「編集者連携」

- `img/02_詳細メニューの編集部連携.png`
- 左の列の「詳細メニュー」→「作品管理」→「編集者連携」を開くと、「作者／編集者切替」「編集者として参加」「校閲開始／終了」「修正を提案する」「校閲を終えて返す」「編集者提案確認」が並ぶ。簡単ステップメニューと同じ操作が、ここからも押せる。
- 編集者モードで使えない操作（「編集者へ渡す」など）は薄い字で「編集者モードでは使えません」と添えて出る。

## 03 編集者として参加（リンクを貼る）

- `img/03_参加のリンクを貼る.png`
- 「編集者として参加」を押すと、上に「編集者として参加」の入力欄が出る。作者から届いたリンク（`https://github.com/…`）を貼り付けて Enter を押すと、作品の取り寄せ・登録・編集者モードへの切り替えが進む。
- 画像のリンクは見本（実際には取り寄せず、Esc で閉じた）。
- この画像は作品を登録する前の画面なので、詳細メニューのほかの行に「作品を登録すると…」と出ている。参加を済ませると 02 の見た目になる。

## 04 校閲する範囲を押さえる（校閲開始／終了）

- `img/04a_校閲の始めの話.png`：簡単ステップメニュー「2. 校閲する範囲を押さえる」→「校閲開始／終了」を押すと、始めの話を選ぶ画面が出る。いちばん上の行は、いま開いている話。始めの話を押す。
- `img/04b_校閲の終わりの話.png`：続けて終わりの話を選ぶ画面が出る。終わりの話を押す（画像では第3話）。
- `img/04c_校閲中を選ぶ.png`：何をしているかを作者へ伝える画面が出る。「校閲中」を押すと、下の帯に「第1話〜第3話を校閲中にしました。」と出る（05a の下の帯に写っている）。

## 05 検知で探す（表記ゆれ検知 → 提案パネルの［適用］）

- `img/05a_表記ゆれの組を選ぶ.png`：簡単ステップメニュー「3. 検知で探す」→「表記ゆれ検知」を押すと、見つかった表記ゆれの組が並ぶ（AI は使わない）。揃えたい組の左の四角にチェックを付けて［OK］を押す。
- `img/05b_揃え先を選ぶ.png`：どちらの書き方に揃えるかを選ぶ。画像では「「ください」に揃える」。
- `img/05c_提案パネルの適用.png`：右に「提案」パネルが開き、直す候補が並ぶ。直したほうがよいものに［適用］を押す。編集者モードでは本文は書き換わらず、作者への提案として置かれる。

## 06 本文を選んで右クリック

- `img/06_右クリックの品書き.png`
- 原稿の本文で直したい所をなぞって選び、右クリックすると品書きが出る。編集者モードでは「修正を提案する」が出るので、それを押す。
- 行への意見だけを伝えるときは、同じ品書きの下のほうの「ここにメモを足す」を押す（0.127.5 で撮り直したので、画像にもその名前で写っている）。

## 07 修正を提案する（2つの入力欄）

- `img/07a_直した案.png`：上に「修正を提案する（1/2）：修正案」の入力欄が出る。最初は選んだ字が入っているので、直した形に書き換えて Enter を押す。空にすると、意見だけを送る。
- `img/07b_ひと言.png`：続けて「修正を提案する（2/2）：理由・意見」の入力欄が出る。直す理由をひと言書いて Enter を押す（空でも送れる）。下の帯に「003_春の灯.txt 3行目に提案を置きました。「校閲を終えて返す」で作者へ届きます。」と出る（08 の下の帯に写っている）。本文は変わらない。

## 08 置いた提案を見る（編集者提案確認）

- `img/08_編集部提案確認.png`
- 簡単ステップメニュー「5. 置いた提案を見る」→「編集者提案確認」を押すと、右下に知らせが出る。画像の知らせの全文は「未決の提案が 2 件あります。採るかどうかは作者が決めます（編集者モードでは決められません）。」（右下では途中までしか見えない）。

## 09 校閲を終えて返す（確認の窓）

- `img/09_校閲を終えて返す確認.png`
- 簡単ステップメニュー「6. 校閲を終えて返す」→「校閲を終えて返す」を押すと、確認の窓が出る。外すロックの数と、送る提案の数が書かれている。［返す］を押すと、提案・ロック・編集履歴が作者へ送られる（本文は送らない）。
- 撮るときは［返す］を押さずに［Cancel］で閉じた（何も送っていない）。

## 10 作者モードへ戻る

- `img/10a_作者モードへ戻る確認.png`：簡単ステップメニュー「7. 作者モードへ戻る」→「作者／編集者切替」を押すと、「この環境を「作者」に戻しますか。」の窓が出る。［作者に戻す］を押す。
- `img/10b_作者モードに戻った.png`：右下に「作者モードに戻しました。すべての機能が使えます。」と出て、簡単ステップメニューが作者向けの並び（1. 作品登録〜7. 電子出版等）に替わる。押す所は無いので囲みは無い。

## 11 作者の採否の知らせと、ベルの一覧（手順7の注記。別の窓で撮る）

- `img/11a_作者の採否の知らせ.png`：作者が採否を送り返したあと、編集者の環境で簡単ステップメニュー「1. 編集者として参加」→「保存・同期」を押す（開いたときも同じ点検が走る）と、右下に「作者が提案を決めました（採用 1・見送り 1・読まれた 1）。」が出る。この知らせを囲む。数秒で消える。
- `img/11b_ベルの一覧.png`：右下のベルを押すと、過去の知らせの一覧に同じ知らせが残っている（ベルとその知らせを囲む）。
- **開き直しで消える**：VS Code を読み込み直すと一覧は空になり、同じ採否は2度知らされない（見たものを覚えている）。読み込み直したあとは、簡単ステップメニュー「5. 置いた提案を見る」→「編集者提案確認」で「未決の提案はありません（これまでに 3 件の提案がありました）。これまでの採否：採用 1・見送り 1・読まれた 1。」が出る（台本で確かめた）。
- 採否の行は台本が台帳へ書いて記録した見本（実際の送り返しは通していない。送り返しの側は `editorDecisionsReturn.test.ts`）。

## 撮れなかった場面・指示との違い

- 撮れなかった場面は無い。
- 表記ゆれの例のうち「ひとつ／一つ」は、表記ゆれ検知の一覧（`src/core/notationVariants.ts`）に無い組なので検知されない。代わりに「ください／下さい」「すべて／全て」を使った。
- 06 の画像は 0.127.5 で撮り直したので、品書きは「ここにメモを足す」「AIに相談（選んだ所）」と写っている。
