# 投稿と読み上げの実機確認（作者の手の手順書）

実機確認リスト（`docs/実機確認リスト.md`）の残りのうち、**作者の手・耳が要る所だけ**を、上から順になぞれるようにまとめたものです。

- 1〜3：投稿サイト・ヘルパーまわり（0.121.0〜0.125.2 の8項目）。本物のサイトと本物のヘルパーが要る所。VS Code の側で起きること（知らせの文・台帳の行・開く URL・案内の文）は、単体テストと画面の自動テストで先に確かめてあります（末尾の表）
- 4：人物の声での朗読（AivisSpeech と VOICEVOX）。耳で聞く所

どの章から始めても構いません。

- 使うもの：統合小説執筆環境（VS Code の拡張機能）0.125.2 以降と、**統合小説執筆環境ヘルパー 0.20.0**（Chrome の拡張機能。ツールバーの拡張機能のアイコン）
- 作品：作品一覧で名前の末尾が `_確認用` の作品を使います。その作品の「投稿サイト設定」には、本物のサイトの作品（カクヨム・アルファポリス・なろう）の作品IDが入っている必要があります
- **投稿・保存・公開のボタンは、どの段でも作者が押します。** 出し直しでは、直したあとの本文が本物のサイトに公開されます。直しても困らない1字（誤字の直しなど）で試してください
- 段ごとに「合格」の印が出なかったら、そこで止めて、出た文をそのまま母艦へ知らせてください

## 0. 準備

1. Chrome でカクヨムにログインし、**作品管理の画面**（`kakuyomu.jp/my/works/作品ID`）を一度開きます。アルファポリスも使うなら、**マイページの作品管理の一覧**（`www.alphapolis.co.jp/mypage/content`）を一度開きます。ヘルパーが「ご自分の作品」を覚えます
2. VS Code の左端の「統合小説執筆環境」のアイコンを押し、「作品一覧」で `_確認用` の作品を右クリック →「投稿と読者の反応…」→「投稿サイト設定」で、カクヨム（とアルファポリス・なろう）が登録されていることを確かめます

## 4. 人物の声で朗読する（リストの読み上げの項目：文と文の間・声の読み分けとエンジンを閉じたとき・感情のスタイル・VOICEVOX）

使うもの：AivisSpeech（入っている声で構いません）、あとで VOICEVOX。作品は `_確認用` の作品の、台詞の多い1話。

**4-0. 読み上げの列を出す**

1. AivisSpeech を起動しておきます
2. VS Code の「作品一覧」で `_確認用` の作品の話を押して開きます。素のエディターで開いたときは、本文を右クリック →「原稿エディターで開く」
3. 原稿エディターの上のバーの［読み上げ］を押すと、読み上げの列（［▶ 読む］［■ 終える］・速さ・声）が出ます
4. 列の［声］で「人物の声（AivisSpeech・VOICEVOX）【試作・テスト中】」を選びます
5. 列の［声の割り当て］を押すと「声の割り当て（この作品の声。選ぶとエンジンの声から選べます）」が出ます。「語り手（地の文）」「台詞の既定」と人物の名前の行を選ぶと、エンジンの声（「話者／スタイル」）から選べます。違いの聞き取りやすい**別の話者**を選んでください（同じ話者のスタイル違いだと聞き分けにくいため）

**4-1. 文と文の間の途切れ**

1. 本文の頭にカーソルを置き、［▶ 読む］を押して、台詞と地の文が入れ替わる所を含めて1〜2分聞きます
2. 合格：文と文の間に、無音の待ち・ぶつ切りが出ない。語り↔台詞の間・文と文の間が自然に聞こえる
3. 読んでいる途中で、列の「速さ」を 1 から 1.3 に変えます。合格：次の文から速くなる
4. ［■ 終える］で止めます → 文と文の間の項目

**4-2. エンジンを閉じたとき**（声の読み分けの項目の後半。0.134.7 から）

1. AivisSpeech を閉じます（窓の右上の×。タスクトレイに残っていたら、そこからも終了します）
2. ［声］が「人物の声」のまま、［▶ 読む］を押します
3. 合格：画面の真ん中に「音声合成のエンジンに繋がりませんでした。」の窓が出て、「AivisSpeech（または VOICEVOX）を起動してから、もう一度［▶ 読む］を押してください。」と「エンジンなしで読むなら、［OSの声で読む］を押すと、いまの場所から OS の声で読みます。」が書いてある
4. 窓の［OSの声で読む］を押します
5. 合格：いまのカーソルの場所から、OS の声で読み始める → 声の読み分けの項目
6. ［■ 終える］で止め、AivisSpeech を起動し直します。［声］が「OSの声」になっていたら「人物の声」へ戻します

**4-3. 感情でスタイルが切り替わるか**

1. 列の［台詞の話者と感情（AI）］を押して、この話の台詞の話者と感情を推定させます（手元の Ollama を使います）。終わったら［台詞の一覧］で、喜び・怒り・悲しみ・ささやき・叫びの台詞がどれかを見ておきます
2. その台詞のあたりから［▶ 読む］で聞きます
3. 合格：その話者に合うスタイル（上機嫌・怒り・悲しみ など）へ切り替わる。0.137.1 からは、**英語の名前のスタイル（Shout・Surprise など）の声でも**感情に合うものが選ばれる。合うスタイルが無い声では、調子（速さ・高さ・抑揚）の寄せだけになる。寄せが大げさすぎないか → 感情のスタイルの項目

**4-4. VOICEVOX でも読めるか**

1. VOICEVOX を公式サイト（https://voicevox.hiroshiba.jp/）から入れて起動します。AivisSpeech は閉じておきます
2. VS Code の左下の歯車のアイコン →「設定」を押します
3. 上の検索欄に `voiceEngineUrl` と打ちます
4. 名前の末尾が「Voice Engine Url」で、説明が「人物の声で朗読するときの、音声合成のエンジンの接続先。」の欄が1つ出ます。その欄の値（`http://127.0.0.1:10101`）を消して、`http://127.0.0.1:50021` と打ちます（打てば保存されます）
5. 原稿エディターに戻り、［声の割り当て］で語り手・台詞の既定・人物の声を VOICEVOX の声から選び直します
6. ［▶ 読む］を押します
7. 合格：AivisSpeech のときと同じに、声が出て、読んでいる文が光り、人物ごとに声が変わる → VOICEVOX の項目
8. 終わったら元に戻します：左下の歯車 →「設定」→ 検索欄に `voiceEngineUrl` → 欄の値を消して `http://127.0.0.1:10101` と打つ。VOICEVOX を閉じ、AivisSpeech を起動して、［声の割り当て］を AivisSpeech の声へ選び直します
