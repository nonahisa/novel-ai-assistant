## 離脱率

- **考え方**：①で「読者流入数（＝第1話のPV）」から最終話まで読み切った人数を引き、①で割る（＝1−最終話読了者数÷①）。作者の最新の式と同じ形。**【普遍】**
- **目安（①より）**：
  - 離脱率100% → 「作品として成立」していない
  - 50話で離脱率約70% → 「WEB小説としては中堅」
  - 離脱率約50% → 「書籍化レベル」
  - 最高値は離脱率**2%程度**（きわめて稀な例として言及）
  - 出どころ：①
- **序盤の脱落（③より、より細かい区切り）**：
  - 1話→2話の間で**8割以上**の離脱 → 「文章力の基礎的欠陥」を示唆
  - 序盤全体で**7割以上**の離脱 → 「序盤のインパクト不足やタイトルと内容の齟齬」を疑う
  - 出どころ：③
- **対策（③より）**：
  - 序盤（1〜2話）の脱落が大きい場合 → 「基礎から修行をやり直」し、**その作品は1から書き直すことを推奨**
  - 安定期（序盤を過ぎたあたり）の読者減少 → 再推敲・再校正で表現を平易にする、話の切れ目を調整する、細かい改稿
  - 第1話への流入そのものが少ない場合 → 更新時間・タイトル・あらすじを変えて興味を引く（これは離脱率というより流入の問題だが、③はセットで扱っている）
  - 出どころ：③
- **読破率という言い方での目安（③より。離脱率の裏返しの数値だが、記事は「一週間ベースの読破率」という別の測り方で出しているため、そのまま併記する）**：
  - 書籍化を狙うなら最低4割、できれば5割程度の読破率を確保
  - 改稿で読破率が10%→35%に回復した実例あり
  - 出どころ：③【普遍（改稿で回復するという経験則）】。ただし「一週間ベース」という区切り方自体は計測の工夫であり、しきい値の数字が④の式（基準の話＝3日以上経過）とそのまま一致するかは記事からは分からない

## 数値の読み方の注意点

- **【古い可能性寄りだが原則は普遍】更新直後のURLを宣伝に使うと数値が歪む。** ①③とも、更新した最新話に直接リンクして宣伝すると、新規読者がその話から読み始めてPVを残すため「正確なデータが取得できなくなる」。**宣伝は必ず作品のトップページURLを貼る**べき、と③にある。原則（直近の更新回にトラフィックを流すと基準が崩れる）自体は普遍だが、「トップページURL」という概念自体はサイト仕様に依る。出どころ：①③
- **【普遍】長編は複数日で集計する。** 「10万文字以上の長編であれば、閲覧に複数日かかるので複数日集計したほうが良い」（③）
- **【普遍】読破率が理論的に計算できるようになるのは安定期の終盤あたりから。** 話数が少ないうちの計測は不安定（③）
- **【普遍】PVは厳密な絶対値ではなく、相対的な人気の目安。** 「厳密ではないけど、だいたい人気度合いを把握できる数字」（①）
- **【普遍】話数ごとに見て、急に読者が減っている回を特定して対策する、という分析の仕方。** 「話数毎に分析して急激に読者が減っている話は何か対策する等」（⑥、2021-02-16）

## 提案（この機能で作れる助言の形。作者の記事の考え方に沿ったもの）

1. **離脱率が①の目安（中堅70%・書籍化50%あたり）を上回ったら、話ごとのPV推移を見せて、どの話で大きく減っているかを指す。** ③の「話数毎に分析して急激に読者が減っている話は何か対策する」という考え方をそのままグラフの読み方に落とす。
2. **1話→2話の間の落ち込みが8割・序盤全体で7割を超えたら、「序盤（1〜2話）の問題」として、③の言う『基礎からの見直し／書き直し』ではなく、まずタイトル・あらすじ・更新時間の見直しを勧める区別を付ける。** ③は序盤脱落と流入不足を別の問題として扱っているので、助言もその区別を保つ。
3. **評価率が①の目安（3割）に近い／超えたときは「伸びている」とだけ伝え、下回っているときの対策は出さない。** ①自体、評価率低下時の対策を書いていないため、こちらも数値の提示にとどめ、憶測で改善案を作らない。
4. **ブックマーク率は、しきい値も対策も記事に無いので、当面は数値の推移を見せるだけにして、目安や助言文は出さない。** 記事に無い基準を作らない、という作者の依頼に沿う。
5. **安定期（序盤を過ぎたあたり）で徐々に離脱が増えている場合は、③の『再推敲・再校正・話の切れ目調整』を提案文の選択肢として出す。** ただし「基礎から書き直す」は序盤の壊滅的な脱落専用の強い助言として区別し、安定期の緩やかな減少には出さない。
