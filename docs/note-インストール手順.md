# 小説を書くためのVS Code拡張機能「統合小説執筆環境」の入れ方

小説の原稿と設定資料をひとつの場所で管理して、AIに手伝ってもらいながら書ける拡張機能を作りました。

作っているのは**小説の作者本人**です。プログラマではありません。だから「便利そうだけど難しそう」で終わらないように、この記事は**パソコンに詳しくない前提**で書きます。上から順にやれば入ります。

**原稿を勝手に書き換えることはありません。** 誤字脱字の指摘も、推敲の提案も、必ず1件ずつ確認してから反映します。

---

## この記事でやること

- VS Code を入れる
- 拡張機能を入れる
- 作品を登録して、文字数が数えられるところまで確かめる
- （使いたい人だけ）AIを動かす準備をする

**AIを使わなくても、作品管理と文字数の集計は動きます。** 途中で止めて構いません。

---

## 用意するもの

**VS Code だけです。**

無料です。Windows でも Mac でも動きます。この記事は Windows の画面で書いていますが、Mac でもほぼ同じです。

---

## ステップ1　VS Code を入れる

すでに入っている方は飛ばしてください。

1. 検索で「VS Code」と調べて、Microsoft の公式サイトを開きます
2. 「Download」を押して、出てきたファイルを実行します
3. 聞かれることは、基本すべて「次へ」で構いません

**バージョン 1.90 以降が必要です。** いま配られているものなら問題ありません。

日本語の表示にしたい場合は、次のステップと同じやり方で「Japanese Language Pack」を入れてください。

---

## ステップ2　拡張機能を入れる

ここが本題です。

1. VS Code を開きます
2. 左端に並んでいるアイコンの中から、**四角が4つ組み合わさったアイコン**を押します（キーボードなら `Ctrl + Shift + X`。Mac は `Command + Shift + X`）
3. 上に出てくる検索欄に、こう入れます

```
統合小説執筆環境
```

4. 出てきたものの「**インストール**」を押します

以上です。

**更新はVS Codeが自動でやります。** 直したり機能を足したりしたとき、こちらで何かする必要はありません。

---

## ステップ3　入ったことを確かめる

VS Code の左端に、**キーボードと万年筆のアイコン**が増えています。名前は「**小説執筆**」です。

見当たらないときは、VS Code をいったん閉じて開き直してください。

押すと、画面の左側に2つの箱が並びます。

- **作品一覧** … 登録した作品と、その話数のファイルが並びます
- **操作メニュー** … できることの一覧です

**操作メニューが要になります。** コマンド名を覚える必要はありません。やりたいことを上から探して押すだけです。

**分類 → 小分類 → 操作**の3階層になっています。

```
執筆データ        執筆統計・文字数
作品管理          GitHubで作品管理／新作開始／既存作追加
執筆AI支援        プロット／校正・校閲／広報支援／その他支援
資料管理          資料生成／設定資料閲覧
拡張機能の設定    設定管理／AI／セットアップを開始
```

まだ作品を登録していないうちは、作品が要る操作は**灰色になって「作品を登録すると使えます」と出ます**。消えるわけではないので、何ができるのかは最初から全部見えます。

---

## ステップ4　作品を登録する

**すでに書いた原稿がある方**は、こちらです。

> 操作メニュー →「作品管理」→「既存作追加」→「**フォルダから追加**」

原稿の入っているフォルダを選んでください。テキストファイル（.txt）でも Markdown（.md）でも読みます。カクヨムや小説家になろうからダウンロードしたファイルも、そのまま置いて構いません。

**これから書き始める方**は、こちらです。

> 操作メニュー →「作品管理」→「新作開始」→「**プロットから開始**」または「**本文から開始**」

登録すると、**話数と文字数がすぐ出ます**。原稿用紙の枚数も出ます。ここまではAIを一切使いません。

**原稿のファイルはそのままです。** 拡張機能が勝手に文字コードや改行を変えることはありません。他のエディタと併用しても壊れません。

---

## ステップ5　AIを使う準備をする（使いたい人だけ）

**入れただけでは、AIを使う機能は動きません。** ここは分けてあります。

AIには2つの選び方があります。

**ひとつめは Ollama です。** 自分のパソコンの中でAIを動かします。**無料で、原稿が外に出ません。** そのかわり、モデルのファイルが大きく、パソコンにそれなりの力が要ります。

**ふたつめは Claude・ChatGPT・Gemini です。** 契約して鍵（APIキー）を登録します。**使うたびにお金がかかります。** そのかわり手元は軽く、賢さも上です。

### Ollama を使う場合

> 操作メニュー →「拡張機能の設定」→「セットアップを開始」→「**セットアップ（必要なものを入れる）**」

押すと、**何が足りていて、それぞれ何のために要るのか**を一覧で見せます。選んだものをその場で入れます。

入るものは次のとおりです。

- **Ollama本体**（約1GB・必須）… パソコンの中でAIを動かす土台です
- **会話モデル `gemma4:e4b`**（約9.6GB・必須）… 設定資料の抽出、あらすじや紹介文、誤字脱字の検知に使います
- **埋め込みモデル `bge-m3`**（約1.2GB・任意）… AIへの相談で、言い換えた質問に強くなります
- **Git**（約60MB・任意）… 複数のパソコンで同じ作品を書く、過去の版へ戻す
- **GitHub CLI**（約12MB・任意）… 非公開のリポジトリを作る、取り寄せる

**全部入れる必要はありません。**

- 1台のパソコンだけで書くなら、Git と GitHub CLI は要りません
- 非力なパソコンなら、埋め込みモデルは入れないほうが軽く動きます

**取得の前に、何をどれだけ落とすか必ず確認します。途中で止められます。** 回線によっては数十分かかります。

### クラウドのAIを使う場合

Ollama とモデルは要りません。

> 操作メニュー →「拡張機能の設定」→「AI」

からAPIキーを登録してください。**実行のたびに課金されます。** そのため、お金のかかるAIで実行するときは、**始める前に必ずその旨をお伝えします。**

---

## できること

入れ終わったら、こんなことができます。

**書く**
話数と文字数の自動集計、原稿用紙換算、執筆量の記録とグラフ、用語のハイライト。

**資料をためる**
本文から登場人物・場所・スキル・組織・世界観を取り出して、設定資料にします。**AIには「本文から取り出す」ことだけをさせて、まとめる作業はプログラム側でやっています。** AIに任せると、同じ人物の呼び方をひとつに畳んでしまうからです。

**整える**
本文からプロットを逆算する。各話あらすじ・作品紹介文・キャッチコピーを作る。各話の盛り上がりを感情曲線で見る。

**直す**
誤字脱字の検知、表記ゆれの検知、推敲の提案、プロットからの逸脱や矛盾の検知。**指摘は1件ずつ確認して適用します。**

方言や口癖を「**直さない語**」として登録できます。「はよ」「あらへん」のような関西弁を「早く」「あらへんで」に直されては、人物が変わってしまうからです。指摘を見たその場で「今後直さない」を押せます。

**相談する**
いま開いている画面についてAIに日本語で聞けます。**質問に近い場面を作品全体から探して答えます。** この拡張機能の使い方も聞けます。

**持ち運ぶ・書き出す**
GitHubで複数の環境を行き来する。競合は並べて見比べて解決する。設定資料集のMarkdown、IME辞書（Google日本語入力・MS-IME・ATOK）の書き出し。

---

## うまくいかないとき

**アイコンが出てこない**
VS Code を閉じて開き直してください。それでも出ない場合は、拡張機能ビュー（`Ctrl + Shift + X`）で「統合小説執筆環境」を探し、インストール済みになっているか確かめてください。

**「作品を登録すると使えます」と出て押せない**
まだ作品を登録していません。ステップ4に戻ってください。

**AIの機能を押すと何か言われる**
Ollama が起動していないか、モデルがまだ入っていません。ステップ5の「セットアップ（必要なものを入れる）」をもう一度実行してください。**何が足りないかを一覧で見せます。**

**AIの応答が返ってこない・遅い**
Ollama は手元のパソコンで動くので、性能に左右されます。1話ぶんの抽出に数分かかることもあります。処理中は**中止ボタン**が出ますので、いつでも止められます。

---

## 消したいとき

拡張機能ビューから「アンインストール」を押してください。

Ollama のモデルは、ターミナルで次のように消せます。

```
ollama rm gemma4:e4b
```

Ollama 本体は Windows の「アプリと機能」から削除できます。

**消しても、作品のファイルや設定資料は変わりません。** 原稿はもともとあなたのフォルダの中にあり、拡張機能はそれを読んでいるだけです。

---

## さいごに

この拡張機能は、**作者が自分で使うために作っています。** 実際に自分の作品で試して、うまく動かなかったところを直す、を繰り返しています。

たとえば誤字脱字の検知は、自分の10作品・44,000字で試したところ、AIが挙げた64件のうち**62件がそのまま通ってしまい**、「保険」→「保険」のような直しようのない指摘が並びました。そこを詰めて、いまは27件まで落としています。

使ってみて困ったところ、こうしてほしいところがあれば、ぜひ教えてください。
