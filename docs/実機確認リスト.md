0.6.13 以降に足したもののうち、**実機でまだ触っていないもの**を並べる（残り646件。数は `- [ ]` の行数で、節を足したら更新する）。

**上から順に潰す必要はない。危ないものから並べてある。**

> **済んだものは消していく。** 残っているものだけが並んでいる状態を保つ。
> 確かめた中身は `進捗と引継ぎ.md` へ書き移してから消すこと（消しただけでは、
> 何を確かめたのかが残らない）。

> **番号は振り直さない。** 落とした節のぶんは飛び番になる（A-7は済んで落とした）。

起動は VS Code で **F5**。「拡張機能開発ホスト」が立ち上がる。

> **拡張機能開発ホストは、ビルドし直しても `Ctrl+R` するまで古いコードで動く。**

単体テストでは、振った番号すべてについて戻り先の行文が元の本文と一致することを確かめてある。だが**実データで通したことは一度も無い。**
