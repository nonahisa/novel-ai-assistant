# 実機（F5）確認リスト

0.6.13 から 0.19.7 までに足したもののうち、**実機でまだ触っていないもの**を並べる（残り291件）。

**上から順に潰す必要はない。危ないものから並べてある。**

> **済んだものは消していく。** 残っているものだけが並んでいる状態を保つ。
> 確かめた中身は `進捗と引継ぎ.md` へ書き移してから消すこと（消しただけでは、
> 何を確かめたのかが残らない）。

起動は VS Code で **F5**。「拡張機能開発ホスト」が立ち上がる。

> **拡張機能開発ホストは、ビルドし直しても `Ctrl+R` するまで古いコードで動く。**
> 直して試すときは必ず再読み込みすること。

## A. 原稿が壊れうるもの（最優先）

**ここだけは、作品のコピーで試すこと。**

### A-1. 誤字脱字・推敲の適用

**適用そのもの（1か所だけ変わるか、二重にならないか、戻せる見た目か）は確認済み**で、リストから落とした。**残っているのは「何を出して、何を出さないか」の見きわめ**である。

#### 出てこなくなったはずの指摘（0.10.22）

**実データ147件で測ったところ、画面に出るのは75件になった。** 消えた分が本当に「押しても意味が無いもの」だけか、目で確かめる。

**AIへ問い合わせ直さなくてよい。** キャッシュに入っているのはAIの生の応答で、検査は毎回そこから行う。もう一度「誤字脱字を検知」を実行すれば、キャッシュのまま件数が減る。

- [x] **修正案が原文と同じ**指摘が、出てこなくなったか（作者の指摘。「相当なお金持ちらしく、恨みも」の形）
- [x] **対象より大幅に長い**（文まるごとの書き換え）指摘が、出てこなくなったか
- [x] 逆に、**まっとうな直しまで消えていないか**（送り仮名・同音異義語・助詞の脱字が、ちゃんと挙がるか）
- [x] 完了時の「指摘 N件 / 除外 M件」の**除外が増えている**か（前回と比べる）

#### 違うところだけが塗られているか（0.10.23）

**目で見るだけで済む。** 本文は書き換わらないので、コピーでなくてよい。

- [x] 推敲の長い指摘で、**変わる箇所だけ**に色が付いているか（行まるごとが赤くなっていないか）
- [x] 消える側に**取り消し線**、足す側に別の色が付いているか
- [x] 塗られている文字が、**本当に変わるところ**か（ずれていないか）
- [x] まるごと書き換わる指摘では、まるごと塗られているか（虫食いになっていないか）
- [ ] 設定資料の更新で、「現在 / 更新案」が上下に並び、**違うひと言だけ**が塗られているか
- [x] テーマを変えても（明るい／暗い）、**色が読めるか**
- [x] 矛盾の指摘は、これまでどおり塗られていないか（意図的にそうしている）

#### 「戻す」（0.10.12で追加。**一度も動かしていない**）

適用済みの指摘に出る「戻す」。**本文を書き換えるので、作品のコピーで試すこと。**

- [x] 戻したあと、**その1か所だけ**が元の語に戻っているか
- [x] 適用 → 戻す → 適用 と往復できるか
- [x] 戻したあと、指摘が**未処理に戻っているか**
- [x] 適用後にその行を手で直してから戻そうとすると、**書き換えずに理由が出るか**
- [x] 戻したあと、**次の検知でその指摘がまた挙がるか**（往復ループ防止から外れているか）
- [ ] 編集部が校閲中のファイルでは、**戻せないか**（理由が出るか）

#### まとめて送るようになった（0.10.8／0.10.9）ぶん

**ここが今いちばん危ない。** 複数の話を1回でAIへ送るようになり、返ってくる行番号は**まとめた本文の通し番号**になった。それを元のファイルの行へ戻してから使う（`locateChunkLine`）。**戻し方を間違えると、別の話のファイルの、まったく違う行が書き換わる。**

単体テストでは、振った番号すべてについて戻り先の行文が元の本文と一致することを確かめてある。だが**実データで通したことは一度も無い。**

- [x] 進捗の分母が、**話数より小さくなっているか**（19話なら6前後）
- [x] **2話目以降の指摘を適用したとき、その話のファイルが変わるか**（1話目が変わっていないか）
- [x] 指摘の「該当箇所へ移動」で、**本当にその文がある行へ飛ぶか**
- [ ] 「まとめて適用」のあと、**各ファイルが1か所ずつだけ**変わっているか
- [ ] 話をまたいだ指摘（前の話の文を後の話の指摘として出す）が**出ていないか**
- [ ] 確認画面に「今回はすべて送り直します」が出るか（**初回だけ**）
- [ ] 2回目に実行したとき、**処理済みとしてスキップされるか**
- [ ] 一度「無視」した指摘が、**本文を1文字直しても復活しないか**（0.10.8で鍵をファイル基準にした）

**まとめる幅は設定 `novelai.mergeChunkChars`（既定6,000字）。** 疑わしいときは `0` にすれば、1話ずつ送る以前の動きに戻せる。**戻して直るなら、原因はまとめ方にある。**

- [ ] 除外の件数が、前より**減っているか**（増えていたら作法が悪さをしている）
