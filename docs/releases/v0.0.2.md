# v0.0.2

v0.0.2は、原稿と作者編集データの保護、登場人物抽出の決定的な品質検証、継続的なCIを中心にした品質改善リリースです。

## 主な改善

- Shift_JISを含む元の文字コード、改行、末尾改行を保持するガード付き原子的書き込みを追加しました。
- 未保存変更、外部変更、競合マーカー、表現不能文字を検出した場合は、安全に書けないため更新を拒否します。
- 人物設定と抽出キャッシュの同時変更・破損・保存競合を検出し、作者のメモ、外部提供メモ、ロック済み呼称、手動管理人物を保護します。
- AI出力を人物種別、名前、本文中の逐語根拠で決定的に検証し、代名詞、集団、場所、根拠不一致を保存前に除外します。
- 固定fixtureにより、抽出漏れ、誤検出、誤統合、作者データ侵害を継続的に検出する品質ゲートを追加しました。
- pull requestと`main`で型検査、単体・品質・coverage・VS Code 1.90.0統合テスト、ビルド、依存監査を実行します。
- VSIXのファイル一覧、manifest、秘密情報・ローカルパス不在、隔離インストール、版を検証する再現可能な配布工程にしました。

## インストール

認証済みのGitHub CLIでprivate repositoryのRelease資産を取得し、VS Codeへインストールします。

```powershell
gh release download v0.0.2 --repo nonahisa/novel-ai-assistant --pattern "novel-ai-assistant-0.0.2.vsix" --clobber
code --install-extension ".\novel-ai-assistant-0.0.2.vsix" --force
```

## 既知の制限

- 本バージョンは原稿をAIで自動修正しません。現在のAI機能は原稿を読み取り、抽出結果を人物設定へ保存します。
- 決定的な検証は明らかな非人物候補や根拠不一致を除外しますが、実モデルの抽出漏れや話者の取り違えまでは保証しません。結果は作者が確認してください。
- Ollama、Claude、Sakura AI Engineの実接続は資格情報やローカルモデルを必要とする手動確認です。通常CIでは外部AIへ接続せず、実モデルの品質や可用性を保証しません。
- プロット、場所・世界観、推敲、矛盾検知、Git同期など、READMEで今後の予定としている機能はまだ含まれません。
