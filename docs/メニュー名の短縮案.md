# メニュー名の短縮案（2026-09-23）

**まだどこにも当てていない案です。** 上から読んで、右端の「可否」に ○・×・別案 を書き込んでください。印の付いたものだけ、とくに見てもらえると助かります。

## 作者の例と、今回の規則

作者の例：「作品名を変更」→「**作品名変更**」／「シリーズとしてつなぐ」→「**シリーズ連結**」／「新しく書き始める」→「**新規執筆開始**」

1. **助詞（を・に・で・から・として・の など）を落とす**
2. **和語の動詞（つなぐ・書き始める・片づける など）を、漢語の名詞に置き換える**
3. **最後は名詞で止める（体言止め）。** すでに十分短いもの（「推敲」「年表」など）は「このまま」

## 印の意味

- **▲** ＝ 詰めると意味が変わる、またはほかの項目と紛れる。案を2つ出すか「このまま」を勧めています
- **このまま** ＝ すでに短い、または固有の名前なので変えない
- 「〔束〕」「〔小分類〕」は、項目ではなく見出しの名前です

## 当てるときのメモ（本体向け）
